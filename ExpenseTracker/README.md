# 💸 Personal Expense Tracker (Core Java)
Mana daily karchulani (expenses) mariyu sampadanani (income) track cheskovadaniki nenu ee Java tool rasa.

### 🔥 Key Features:
- **Transaction Logging:** Income mariyu Expense types ni add cheyochu.
- **Categorization:** Food, Travel, Bills, Salary lanti categories unnai.
- **Balance Analysis:** Total income, Total expense, mariyu net balance automatic ga calculate chestundi.
- **Data Overview:** Anni transactions ni neat ga table format lo chudochu.

### 🛠️ Tech Stack:
- Java (ArrayLists for dynamic data storage)
- Scanner class for user interaction
