# 💸 Personal Expense Tracker (Core Java)
Mana daily karchulani (expenses) track cheskovadaniki nenu ee simple Java tool rasa.

### 🔥 Key Features:
- **Add Expenses:** Amount, Category (Food, Rent, etc.), and Date enter cheyochu.
- **Budget Tracking:** Monthly budget set cheskuni, manam limit cross avtunnama leda chudochu.
- **Reports:** Category-wise spending reports and total balance summary.
- **History:** Pata expenses anni list laaga chudochu.

### 🛠️ Tech Stack:
- Java (Collections for storing data)
- File Handling (Optional: Data ni save cheskodaniki use cheyochu)
