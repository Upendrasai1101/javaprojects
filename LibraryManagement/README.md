# 📚 Library Management System (Core Java)
Library operations ni automate cheyadaniki nenu ee simple Java application rasa.

### 🔥 Key Features:
- **Book Inventory:** Add, Update, Search, and Delete books.
- **Issue/Return System:** Members ki books issue cheyadam mariyu return tiskovadam.
- **Search Options:** ID, Name, Author, leda Category batti search cheyochu.
- **Live Statistics:** Total books, issued books, mariyu category-wise reports.

### 🛠️ Tech Stack:
- Java (ArrayLists for data storage)
- Scanner for user input
