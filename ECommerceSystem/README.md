## 🚀 Overview
**E-Commerce Console Application** is a lightweight Java-based console program that simulates an online shopping experience with interactive product catalogs, shopping carts, virtual wallets, and order history tracking.

---

## ✨ Features

* **🛍️ Product Catalog:** Browse through a variety of available products including Laptops, Mobiles, and daily essentials.
* **🛒 Cart System:** Add items to your shopping cart, update quantities, or remove items seamlessly.
* **💳 Wallet & Checkout:** Manage your starting wallet balance and checkout orders securely.
* **📜 Order History:** View past completed orders and transaction logs.

---

## 🛠️ Tech Stack

* **Language:** Core Java (Object-Oriented Programming)
* **Environment:** Command-Line Interface (CLI)
* **Tools:** Java Compiler (`javac`), Git

---

## ⚙️ How to Run

Compile and run the application directly from your terminal or command prompt:

```bash
# Compile the Java file

# Run the application
