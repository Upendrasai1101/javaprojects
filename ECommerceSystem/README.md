# E-Commerce Console Application 🛒
Java lo create chesina oka simple online store simulation.

### Features:
- **Product Catalog:** Laptop, Mobile lanti 10 products list chudochu.
- **Cart System:** Items ni cart ki add cheyadam, remove cheyadam.
- **Wallet:** Starting balance tho checkout cheyadam.
- **Order History:** Pata orders list chudochu.

### How to Run:
`javac ECommerceApp.java`
`java ECommerceApp`
