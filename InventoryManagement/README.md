# 📦 Inventory Management System (Core Java)
Business stock ni mariyu profits ni track cheyadaniki nenu ee robust Java application rasa.

### 🔥 Key Features:
- **Stock Tracking:** Products ni add, update, mariyu delete cheyochu.
- **Profit Analytics:** Buy price mariyu Sell price ni batti potential profit ni automatic ga calculate chestundi.
- **Low Stock Alerts:** Stock thaggipoyina products ni "Low Stock" ani highlight chestundi.
- **Category Breakdown:** Prathi category lo enni products unnaio report isthundi.
- **Transaction History:** Stock updates annitini log chestundi.

### 🛠️ Tech Stack:
- Java (ArrayLists for data storage)
- Business Logic (Profit/Loss calculations)
