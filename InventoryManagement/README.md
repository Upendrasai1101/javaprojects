## 🚀 Overview
**Inventory Management System** is an efficient backend program built using Core Java. It helps small-to-medium businesses handle stock levels, calculate profit margins dynamically, and monitor inventory shortages with automated alerts.

---

## ✨ Key Features

* **📦 Stock Tracking:** Add, update, and delete products dynamically from the inventory catalog.
* **💰 Profit Analytics:** Automatically calculates potential profits based on buying and selling prices.
* **⚠️ Low Stock Alerts:** Instantly highlights products that fall below safety thresholds as "Low Stock".
* **📊 Category Breakdown:** Generates summaries and reports on the number of products available per category.
* **📜 Transaction History:** Maintains logs for all inventory modifications and updates.

---

## 🛠️ Tech Stack

* **Language:** Core Java (ArrayLists, Object-Oriented Programming)
* **Logic:** Business calculations for profit and loss analysis
* **Tools:** Java Compiler (`javac`), Git
